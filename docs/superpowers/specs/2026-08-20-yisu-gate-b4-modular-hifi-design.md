## 5. 模块化组件

在 `06B Hi-Fi Components` 中新增或补齐以下可复用组件集；页面必须优先使用实例：

### 5.1 Content State

统一承载内容区域状态，变体为：

- `State=Content`
- `State=Empty`
- `State=Loading`
- `State=Error`
- `State=No Results`

组件公开标题、说明、插图/图标和主操作文案属性。加载态使用骨架，不使用不可控动画；错误态提供重试入口。

### 5.2 Category Filter

- 单项状态：`Default`、`Selected`、`Pressed`、`Disabled`。
- 组合组件包含：全部、上衣、裤子、外套、裙子、鞋子、配饰、其他。
- 横向滚动由容器控制，组件本身不裁切文字。

### 5.3 Garment Collection

- `Garment Card`：`Default`、`Pressed`、`Loading`、`Image Error`。
- `Garment Grid`：两列布局，只负责卡片排列与间距。
- 名称最多两行，元数据一行；不得再次出现第二行被遮挡的问题。

### 5.4 Form Modules

- `Form Section`：重要信息、其他信息的视觉容器，不显示多余章节标题。
- `Field Row`：文本、单选、多选、日期、层级选择、数字输入。
- 状态：`Default`、`Focused`、`Filled`、`Error`、`Disabled`。
- P08 重要字段为图片、名称、分类、季节、收纳位置、备注；其余字段进入次要区。

### 5.5 Photo Module

- `Photo Hero`：`Empty`、`Loaded`、`Loading`、`Error`。
- 右下角入口根据上下文显示“添加照片”或“换图”。
- 取消照片选择始终返回原始起点：P05 添加入口返回 P05，P08 返回 P08，P09 换图返回 P09。

### 5.6 Auto-save Status

变体为：`Idle`、`Saving`、`Saved`、`Error`。错误态提供重试，不阻塞返回和浏览；文本字段停顿约 800ms 或失焦后提交，选择类字段完成选择后立即提交。

### 5.7 Confirm Dialog

删除确认作为组件：`Default`、`Deleting`、`Error`。默认态包含取消和危险操作；错误态保留重试与取消。对话框不得成为独立页面。

### 5.8 Bottom Navigation

复用现有 `衣橱｜添加衣物｜我的`，只补充 `Wardrobe Selected` 与 `Profile Selected` 页面实例。中央加号始终是主操作，不作为普通 Tab。

## 6. 原型范围

`08 Hi-Fi Prototype` 只连接以下核心路径：

1. P05 → 搜索 → 选择结果 → P09。
2. P05 → 中央添加衣物 → P08 → 照片入口/字段编辑。
3. P05 → 衣物卡 → P09 → 字段修改 → 自动保存状态。
4. P09 → 更多 → 删除确认 → 删除中/失败或返回 P05。
5. P05 → 我的 → P12 → 协议页或退出登录。

空、加载、错误、无结果和筛选状态放在组件评审区，不为每个状态创建独立原型页面；仅当演示交互需要时使用覆盖层或组件变体。

## 7. Token 节省规则

- 先构建并审计组件，再创建整页实例。
- 同一种状态只在组件集中定义一次，不复制到每个页面。
- 复用 Gate B1 确认稿和现有真实衣物抠图，不重新生成图片。
- Figma 写入按“组件批次 → 关键页面批次 → 原型连线 → 审计”执行，避免逐节点往返。
- 检查使用结构化脚本一次性输出节点数量、字体、描边、溢出、组件实例和原型目标。
- 截图仅保存整板、组件集和关键路径代表页面，不逐个保存等价状态。
