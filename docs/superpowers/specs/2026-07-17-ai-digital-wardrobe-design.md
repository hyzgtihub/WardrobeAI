# AI 数字衣橱 App 产品设计

日期：2026-07-17  
状态：待用户书面审阅  
首发平台：iPhone 原生 App  
产品阶段：MVP

## 1. 产品定位

这是一款面向爱穿搭女性的 iPhone AI 数字衣橱 App。用户通过单件拍照，将现实中杂乱的衣物快速转换成可分类、搜索、搭配和记录的线上衣橱。

产品首版优先解决“整理衣橱很费时间”和“忘记自己拥有什么”两个问题。核心差异是低负担的 AI 录入，以及支持为自己、宝宝等不同角色建立独立衣橱。

## 2. 目标用户与核心场景

### 2.1 核心用户

- 衣服较多，希望快速整理、查找并减少重复购买的女性。
- 喜欢搭配和记录 OOTD，但不愿逐项手工创建衣物档案的女性。
- 需要同时管理自己和孩子衣物的妈妈。

### 2.2 核心场景

1. 用户整理衣柜时逐件拍照，系统自动去背景、识别属性并归类。
2. 用户在外购物时查看已有衣物，判断是否已有相似款式。
3. 用户在 App 中选择已有衣物组成搭配，并保存为穿搭方案。
4. 用户记录当天 OOTD，积累衣物的穿着历史。
5. 妈妈切换到宝宝角色，记录尺码和复购评价，避免重复购买不合适款式。

## 3. MVP 范围

### 3.1 必须实现

- 账号登录、云端同步、换机恢复、账号注销和数据删除。
- 创建、编辑和切换衣橱角色，默认角色为“我”。
- 从相机或相册录入单件衣物。
- 上传前检查照片模糊、过暗和明显包含多件衣物等问题。
- 自动去背景并识别基础衣物属性。
- 用户确认或修改识别结果后保存。
- 衣物的新增、查看、编辑、删除、搜索和筛选。
- 分类优先的衣橱首页，以及智能集合和衣物卡片状态标签。
- 创建并收藏简单搭配。
- 使用已有搭配或衣物记录 OOTD。
- 将搭配或 OOTD 生成图片并由用户主动分享。

### 3.2 重要特色

- 基础多角色衣橱。
- 宝宝衣物尺码。
- “值得复购”和“不再购买”标记。
- OOTD 自动更新衣物的最近穿着时间。

### 3.3 明确后置

- 拍摄整个衣柜并自动拆分多件衣物。
- 灵感内容流、达人体系、关注、评论和公开社区。
- 深度风格、体型或肤色推荐。
- 自动生成完整穿搭。
- 虚拟试穿。
- 家庭成员共同编辑。
- 二手交易和商品导购。
- 宝宝成长尺码预测和自动换码提醒。
- 每个角色独立选择分类、大图或列表视图；MVP 统一使用分类卡片视图。

## 4. 信息架构与导航

底部导航固定为四个入口：

1. **衣橱**：默认首页，负责角色切换、分类浏览、智能集合、搜索、筛选和衣物管理。
2. **搭配**：选择当前角色的衣物创建、编辑和收藏搭配。
3. **OOTD**：以日历形式记录每日穿搭。
4. **我的**：角色管理、会员、账号、隐私和数据管理。

跨页面始终保持当前角色上下文。切换角色后，衣橱、搭配和 OOTD 均显示该角色的数据，不混合展示。

## 5. 核心用户流程

### 5.1 首次使用

1. 用户完成账号登录。
2. 系统创建默认角色“我”，用户可编辑名称和头像。
3. 系统说明照片用途、隐私方式和相机/相册权限。
4. 用户拍摄或选择第一件衣物照片。
5. 系统完成画质检查、上传、去背景和属性识别。
6. 用户在确认页修改必要字段并保存。
7. 新衣物立即出现在当前角色衣橱。
8. 系统引导用户继续录入或创建第一套搭配。

### 5.2 日常录入

1. 用户在衣橱页点击“录入”。
2. 用户选择拍照或相册。
3. 若照片质量不合格，系统解释原因并允许重拍或仍然继续。
4. 若 AI 处理成功，确认页预填识别结果。
5. 若 AI 处理失败，保留原图并进入手动填写状态。
6. 用户保存后，系统同步云端并更新分类数量和智能集合。

### 5.3 搭配和 OOTD

1. 用户在当前角色下选择多件衣物组成搭配。
2. 用户保存搭配，可添加名称和备注。
3. 用户在 OOTD 日历选择日期并关联已有搭配，或直接选择衣物。
4. 保存 OOTD 后，相关衣物的最近穿着时间自动更新。

## 6. 衣橱首页融合方案

### 6.1 默认结构

- 顶部：当前角色切换、搜索、筛选和录入入口。
- 第一层：智能集合，包括最近添加、最近穿过、我的最爱和当季衣物。
- 第二层：全部、上衣、裤子、连衣裙、外套等品类。
- 主内容：当前集合或分类中的衣物卡片网格。
- 衣物卡片：去背景衣物图、名称、品类和最多两个优先级最高的可见标签。

### 6.2 标签规则

- **最近添加**：录入时间在最近 30 天内，系统自动生成。
- **最近穿过**：存在 OOTD 记录，并按最近穿着时间排序，系统自动生成。
- **当季衣物**：衣物季节标签与当前月份匹配，系统自动生成；用户可修改衣物季节。
- **我的最爱**：用户主动标记。
- **值得复购**：用户主动标记。
- **不再购买**：用户主动标记。

同一件衣物可拥有多个标签。卡片空间不足时，按“用户主动标记优先于系统标签”的规则展示，其余标签在衣物详情中完整显示。

## 7. 数据模型

### 7.1 角色

- 角色 ID
- 所属账号 ID
- 名称
- 头像
- 角色类型：本人、宝宝、伴侣、其他
- 创建时间
- 最近使用时间

### 7.2 衣物

- 衣物 ID
- 所属角色 ID
- 原始图片
- 去背景图片
- 名称
- 主品类与子品类
- 主颜色
- 适用季节，可多选
- 品牌，可选
- 尺码，可选
- 购买时间，可选
- 备注，可选
- 是否为最爱
- 复购评价：未设置、值得复购、不再购买
- 状态：在用、闲置、已淘汰
- 创建时间
- 最近穿着时间，可空
- AI 识别状态与用户是否修正过识别结果

### 7.3 搭配

- 搭配 ID
- 所属角色 ID
- 名称
- 衣物 ID 列表
- 预览图
- 备注
- 创建和更新时间

### 7.4 OOTD

- OOTD ID
- 所属角色 ID
- 日期
- 关联搭配 ID，可空
- 关联衣物 ID 列表
- 用户照片，可选
- 备注
- 创建和更新时间

## 8. 异常、隐私与数据完整性

- 照片模糊、过暗或疑似包含多件衣物时，在上传前提示具体原因。
- AI 识别失败不阻断录入；保留原图，允许用户手动选择品类并保存。
- 网络中断时保存本地待上传任务，恢复连接后自动重试。
- 防止同一待上传任务被重复创建；重复照片检测不作为 MVP 强制功能。
- 删除衣物前显示其关联搭配和 OOTD 数量。
- 用户确认删除后，衣橱中移除该衣物；历史 OOTD 保留日期和已删除占位，避免记录被静默改写。
- 所有云端图片默认私密，不自动公开。
- 只有用户主动生成分享图时，才产生可分享内容。
- 首次使用明确说明相机、相册、图片处理和云存储用途。
- 用户注销账号时提供明确二次确认，并支持删除账号及云端数据。

## 9. 免费版与会员

采用“免费基础版 + 会员”模式。

### 9.1 免费版

- 一个角色。
- 基础衣橱管理、搭配和 OOTD。
- 有限的 AI 衣物录入与云端容量。
- 基础搜索、筛选和标签。

### 9.2 会员

- 创建多个角色。
- 更高的 AI 录入额度和云端容量。
- 后续版本的高级 AI 推荐、统计分析和更多视图能力。

MVP 不将基础搭配和 OOTD 完全设为付费功能，以便验证用户是否会从衣物管理进入持续使用。具体免费衣物数量、AI 次数、存储容量和订阅价格，需要在开发计划前结合 AI 与存储成本单独测算。

## 10. 系统边界与组件

- **iPhone 客户端**：登录、权限、拍摄、相册、页面交互、本地待上传队列和本地缓存。
- **业务服务**：账号、角色、衣物、搭配、OOTD、会员权限和同步。
- **图片服务**：原图上传、去背景图生成、缩略图和私有访问。
- **AI 识别服务**：品类、颜色和季节属性建议，并返回置信度。
- **任务处理**：协调图片处理和 AI 识别状态，支持失败重试。

客户端不依赖 AI 成功才能创建衣物。AI 输出始终是可编辑建议，用户确认后的数据才作为正式衣物属性。

## 11. 成功指标

### 11.1 核心体验指标

- 新用户完成默认角色创建并成功录入第一件衣物。
- 正常网络下，从提交照片到进入可保存确认页的目标时间不超过 30 秒。
- 用户在 AI 判断错误时可以直接修改并完成保存。
- 用户可在三次点击内进入指定分类或智能集合。
- 用户换机登录后可恢复已同步数据。

### 11.2 产品验证指标

- 首次衣物录入完成率。
- 新用户首日录入衣物数。
- 7 日内再次打开衣橱的用户比例。
- 创建第一套搭配和第一条 OOTD 的用户比例。
- AI 结果未经修改直接保存的比例。
- 多角色创建率。
- 宝宝尺码、值得复购和不再购买标签的使用率。
- 免费用户触达额度限制后的会员转化率。

MVP 上线前不预设数值目标；先通过小规模测试建立基线，再设定正式目标。

## 12. 测试与验收

- 不同光线、背景、材质和颜色衣物的拍摄与识别。
- 照片过暗、模糊、裁切不完整和多件衣物入镜。
- 去背景或属性识别失败后的手动保存。
- 上传过程中断网、切后台、恢复网络和重复点击。
- 新增、编辑、删除、搜索和多条件筛选。
- 角色创建、切换和数据隔离。
- 智能集合与卡片标签的生成和更新。
- 宝宝尺码与复购评价的保存和筛选。
- 搭配引用衣物，以及衣物删除后的关联提示。
- OOTD 更新最近穿着时间，以及历史删除占位。
- 换机恢复、账号注销和云端数据删除。
- 免费额度耗尽、会员状态变化和权限降级。

## 13. 已确认决策

- 目标用户为爱穿搭女性，宝妈是重要特色场景但不是唯一人群。
- MVP 核心价值为快速整理衣橱。
- 首发为 iPhone 原生 App。
- 录入采用单件拍照自动识别，不做整柜多件拆分。
- 采用账号登录和云端同步。
- 基础多角色纳入 MVP，并作为会员能力。
- 首页采用分类优先与视觉衣橱融合方案。
- 免费基础版加会员订阅。

## 14. 后续规划前必须补齐

- AI 去背景与属性识别服务的成本、速度和质量验证。
- 免费额度、会员价格和存储上限。
- 首批种子用户规模与测试方式。
- iPhone 最低系统版本及无障碍要求。
- 国内运营所需的隐私政策、数据处理和内容分享合规要求。
